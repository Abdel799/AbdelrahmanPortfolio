# Abdelrahman's Portfolio

**Welcome to my portfolio website**

In this website you'll find several projects I've worked on throughout the years including:

- **Chat Flow:** A real-time messaging application including login authentication, online user statuses, room-based messages, & live typing indicators.
- **Lofi Nest:** A study platform that incorporates music streaming, AI assistance, calendar functionality, note-taking, & a timer.
- **Cost of Living Dashboard:** A dashboard that houses all of Canada's expenses ranging from grocery prices to housing rent, used to determine affordability for Canadian residents.
- **Uber Command-Line Program:** A program that simulates the real-life Uber application showcasing object-oriented programming in Java
- **Snake Game:** A snake game built with Java & JavaFX
- **Wordle Command-Line Program:** A program that simulates the real-life Wordle application

This website also incorporates my internship experiences and how to connect :)

This website was built with React.js, JavaScript, and CSS.
